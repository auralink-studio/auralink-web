AuraLink Studio / 知音 · Zhiyin

正式版 v1.0.0 · Windows · VST3

照着耳朵的听感，
重新平衡音色。

知音像人耳一样聆听音乐，并持续调整一条平滑的均衡曲线：压低那些过于突出的刺耳、轰鸣与共鸣，让存在却被盖住的细节浮现出来。没有需要手动摆放的频段 —— 你只需决定处理的力度和平衡的方向，在哪里处理由插件每时每刻自行判断。

目前支持 Windows 10/11（64 位），可在任何支持 VST3 的 DAW 中使用。下载包内含录音室版、现场版和母带版三个版本。

与众不同之处

不用摆频段，只管听。

普通均衡器要你自己一个个找出问题频率 —— 而它们还会随着歌曲段落不断变化。知音替你时刻盯着这一切。

  • 驯服刺耳、轰鸣与共鸣过于突出、主导听感的频率会在出现的那一刻被压低，消失后随即放开。
  • 恢复被掩盖的细节存在却被相邻较响频率盖住的部分，会被提升到刚好能被人耳听清。
  • 两个旋钮决定方向偏向决定更多恢复还是更多驯服；明亮把平衡向高频或低频倾斜。
  • 公平对比，不被音量骗耳朵自动增益保持感知响度不变，旁通保持延迟不变 —— 开关之间听到的是音色差异，而不是音量差异。
  • 划定处理范围低频界限与高频界限可以避开底鼓、贝斯或顶端的空气感，两端平滑过渡。
  • 不碰底噪静音与底噪不会被“修正”；远低于周围、怎么提升也听不见的成分也不会被提升。
三个版本

一双耳朵，三种工作。

按手上的工作选择：混音、录音与现场，或母带。三个版本都在同一个下载包里。

录音室版 Studio

用于混音、单轨与总线，低频分辨率高。主题色：竹林绿。

  • 延迟（48 kHz）42.7 ms
  • 处理精度32 位
  • 最大修正±12 dB

现场版 Live

用于录音监听与现场演出，低延迟，适合实时使用。主题色：荷花粉。

  • 延迟（48 kHz）10.7 ms
  • 处理精度32 位
  • 最大修正±9 dB

母带版 Master

用于母带与总线精修，增加响应、范围与立体声 / 中侧模式。主题色：枫叶橙。

  • 延迟（48 kHz）85.3 ms
  • 处理精度64 位双模型
  • 最大修正3–18 dB（范围）
使用建议

默认设置已很温和，多数素材 20–50 % 就够。

混音总线 / 编组

录音室版：恢复 30–40 %，驯服 30–50 %；低频界限设在 60–80 Hz 左右，保护底鼓和贝斯。

人声

驯服处理刺耳的共鸣和齿音区，恢复让被伴奏盖住的清晰度回来；高频界限设在 12–16 kHz 可保留空气感。

母带

母带版：范围 3–6 dB，响应 30–50 %，处理宜轻；两侧需要单独整理时使用中 / 侧。

开始使用

复制到 VST3 目录，重新扫描即可。

解压下载包，把 Zhiyin Studio.vst3、Zhiyin Live.vst3 和 Zhiyin Master.vst3 复制到 C:\Program Files\Common Files\VST3，然后打开 DAW 重新扫描 —— 三个插件都在厂商 AuraLink Studio 之下。界面支持中文、English 与 Tiếng Việt。
